# 02 · Too many tools will eat your context: from tool search to PTC

**Read:** [on X](https://x.com/Ronny_MiniMax/status/2115044823648628998)

**In one line:** tools cost context through their definitions and through
their results. Subtract first, then defer rarely used tools behind tool
search, then let the model write programs that call tools (PTC). Each step
lays the groundwork for the next; measure at every step.

**Companion skill:** `tool-budget-audit` - measure what tools cost, then pick
between trimming, tool search and programmatic tool calling.

Plain-text checklist: [`checklists/tool-budget.md`](../stacks/ronny/checklists/tool-budget.md)
