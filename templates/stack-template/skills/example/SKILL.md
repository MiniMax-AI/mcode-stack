# Example skill

Rename the `example` directory and the `name` above to your skill's id
(lowercase letters, digits and hyphens). They must match.

Write the steps you actually follow, in the order you follow them. Good skills
usually have:

1. **When to use it** - the situation that triggers it.
2. **Inputs** - what the agent should gather first, from real sources.
3. **Steps** - concrete actions, with the checks that tell you each step worked.
4. **Output** - what the agent should hand back at the end.

Keep it short. If you cannot say where your agent would go wrong without this
skill, it probably belongs inside another skill.
