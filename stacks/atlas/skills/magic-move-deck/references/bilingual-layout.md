# 双语排版约定（中英双语 deck）

全程中英双语、英文为主的 deck：所有图（封面、总览、细节图、结束页）英文在上、字号大，中文在下、字号小，两种语言的文案各自完整。纯中文或纯英文 deck 跳过本文件，只需保证节点名与分区名两页一致。

## 本地函数（定义在 `main()` 开头，见 `templates/detail-main.js`）

参数一律按 `(中文, English)` 传，显示顺序由函数决定：

| 函数 | 输出 | 用在 |
|---|---|---|
| `bl(zh, en, zhSize = 13)` | 两行：英文在上，中文在下、字号 `zhSize` | 箭头说明、小标签 |
| `fl(zh, en)` | 单行 `English&emsp;中文`，中间是全角空格（em space），中文 14px | **所有分区框标签**（`build_deck.py` 按 em space 拆出中文分区名） |
| `btext(x, y, w, h, color, [zh, en], subs, o)` | 框内标题 + 细项：标题英文 `size`、中文 `zhSize`；每个细项英文在上、中文在下（`subSize` / `zhSubSize`）；`'gap'` 插空；整块按实际高度垂直居中 | 节点正文 |
| `bnode(...)` | `box()` + `btext()` | 大多数节点 |

`btext` 的中文标题行用 `.ti`（加粗），所以它就是节点的配对名。

## 标题与字号

| 图 | 英文 | 中文 | 排法 |
|---|---|---|---|
| 细节图标题 | 40px | 28px | 同一基线，先 `title()` 英文，再 `title()` 中文，中文 x = 英文宽度 + 24 |
| 细节图副标题 | 21px | 18px | 各占一行（y=104 / 134） |
| 总览标题 | 42px | 30px | 同基线，间隔 +26 |
| 封面标题 | 72px | 44px | 居中两行 |
| 结束页标题 | 64px | 38px | 居中两行 |

## 圈号（①–⑳）

- 总览上每个原则 / 主题有一个以圈号开头的英文小标题，正下方一行中文；细节图英文标题以同一个圈号开头，这样标题从小标题放大而来。细节图的中文标题与小标题下方那行中文用同一段文字。小标题放在该主题区域之外（标题带），见 `examples/rag-assistant/overview.html`。
- 圈号放在英文行。实在放不下时可以放中文行，但要在代码里注释原因。
- 步骤序号（「1 · xxx」）可以放中文行，不影响配对。

## 文案

- 不写内部服务名、厂商产品名或代号，用通用名（如不写某云厂商的存储产品名，写「对象存储」「云盘 · NAS」；不写内部服务代号，写「出口代理」「模型网关」）。对外分享的 deck 尤其要守。
- 英文文案以官网 / 产品原文为准，不自造 slogan。
- 「图例 · Legend」是 helper `legend()` 里写死的，不改。
