# req-tpm: which skill, when

English | [中文](WORKFLOW_ZH.md)

| Moment | Skill |
| --- | --- |
| Someone raises a requirement | `req-intake` |
| Iteration planning, or someone wants to jump the queue | `req-prioritize` |
| Scheduled, before development starts | `req-design` |
| Every workday or weekly follow-up | `req-track` |
| Getting ready to ship | `req-ship` |
| Observation window ends, or someone wants to close it | `req-outcome` |

During the pilot we use this inside the MiniMax Code team first. After each
requirement runs the full chain, we leave a short usage note in its doc as
the basis for opening it up further.
