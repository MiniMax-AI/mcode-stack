# 检索增强问答助手 · 概念配色绑定

整套 deck（封面、总览、3 张细节图、结束页）共用这张表；每张图 `main()` 顶部的 "Concept color binding" 注释与本表一致。新概念只追加新行，不改已有行。

## 概念 → 颜色 → 形状

| 概念类别 | 包含组件 | 颜色 slot | 形状 |
|---|---|---|---|
| 用户 | 用户（提问、读回答、点引用） | `C.user` 钢蓝 | Box |
| 知识数据 | 文档 · 向量索引 · 关键词索引 · Top-k 片段 | `C.memory` 栗棕 | Box；文档、Top-k 片段为堆叠框 `stack()`（多份） |
| 入库处理步骤 | 解析清洗 · 切块（细节图里的片段卡片） | `C.tools` 苔绿 | Box；片段卡片为 `taskCard()` |
| 辅助模型 | 向量模型 · 重排序 | `C.subagent` 焦糖 | Box |
| 检索编排（主角） | 查询改写 · 混合检索 · 合并去重 · 权限过滤 · 向量召回 · 关键词召回 · 提示词组装 · 证据检查 | `C.agent` 砖橙 | Box；混合检索、提示词组装加粗（`strokeWidth: 3.2`）；提示词的三段为 `taskCard()` |
| 大模型 | 大模型 | `C.llm` 靛紫 | Box |
| 回答 | 带引用的回答 | `C.im` 墨青 | Box |
| 拒答 | 证据不足时拒答 · 说「不知道」 | `C.error` 砖红 | Hexagon + 红色虚线箭头 |
| 分区 | 离线入库 ① / 在线检索 ② / 回答生成 ③ | `C.tools` / `C.agent` / `C.llm` | `frame()` 虚线框 + `fl()` 标签 |
| 流向 | 所有正常箭头 | `C.flow` 暖墨 | `arrow()` / 折线 `route()` |
| 封面 / 结束卡片 | 卡片边框、标题、下划线 | `C.card`（风格自带） | `box()` |

## 歧义概念的裁决

- 向量模型、重排序 → 辅助模型（`C.subagent`），不是大模型（`C.llm`）。理由：它们只打分 / 编码，不生成回答；`C.llm` 只留给生成回答的那个模型。
- 提示词组装 → 检索编排（`C.agent`），不是大模型。理由：它是编排代码拼出来的输入，大模型只负责读它。
- Top-k 片段 → 知识数据（`C.memory`），不是检索编排。理由：它是检索的结果数据，和索引里的片段是同一种东西。
- 证据检查 → 检索编排（`C.agent`），不是拒答（`C.error`）。理由：检查本身是正常流程；只有「检查不通过 → 拒答」这条路径用红色。
